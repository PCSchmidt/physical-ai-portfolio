# Security Policy

## Scope

This repository is an index of personal portfolio projects. The projects use public data and unclassified, synthetic scenarios only. RF work is receive-only.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting (Security tab → "Report a vulnerability") rather than a public issue. Include the affected project, steps to reproduce, and impact.

This is a personal project maintained on a best-effort basis; there is no guaranteed response time.

## Out of scope

Do not submit controlled, classified, or employer-owned information to this repository in issues, pull requests, or discussions.
